# React Hooks Exercises XP

A small React app containing the two Week 8 Day 3 XP exercises:

- **Theme switcher:** `ThemeProvider` stores the light/dark theme with `useState`; the header and page read it with `useContext`.
- **Character counter:** an input `ref` reads the current value on each input event and updates the live character count.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

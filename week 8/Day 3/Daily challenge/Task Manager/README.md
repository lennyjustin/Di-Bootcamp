# Enhanced Task Manager

A React task manager exercise using `useContext`, `useReducer`, and `useRef`.

## Features

- Add tasks and mark them complete.
- Edit task text inline, with the input focused using a ref.
- Remove tasks.
- Filter by all, active, or completed tasks.
- Persist tasks in browser local storage.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

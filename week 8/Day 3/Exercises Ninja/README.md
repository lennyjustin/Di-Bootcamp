# React Task Manager — Exercises Ninja

A small task manager showing how separate React components can read and update
shared state with `useContext` and `useReducer`.

## Features

- Add tasks.
- Mark tasks complete or active.
- Remove tasks.
- See the task list and completion summary update from shared context state.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

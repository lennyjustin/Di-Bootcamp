# Herolo Weather

A responsive two-page weather app with city search and locally saved favorites.
Weather data comes from the free Open-Meteo geocoding and forecast APIs, so no
API key or server is required.

## Features

- Search cities and view current conditions plus a five-day outlook.
- Save and remove favorite cities using browser local storage.
- Navigate between the weather and favorites pages.
- Open a saved city directly from the favorites list.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

# MicroSACCO AI — Portfolio Starter

A browser-based SACCO administration dashboard and member-facing portal built with HTML, CSS, vanilla JavaScript, PHP, and MySQL/MariaDB.

## Included

- Dashboard and member portal layout
- Member registration and KYC flow
- Savings deposits and withdrawals
- Loan application and repayment logic
- Share purchase tracking
- CSV export and basic reporting
- Role-based staff and member access
- Daraja STK Push scaffold

## Setup

1. Import `database/schema.sql` into MySQL.
2. Configure `config/config.php`.
3. Open `public/setup.php` to create the admin account.
4. Sign in at `public/index.php`.

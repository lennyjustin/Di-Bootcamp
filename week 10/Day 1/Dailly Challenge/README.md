# Building a TypeScript and React Todo

This daily challenge is a small book-list app demonstrating TypeScript generics
with React. The reusable `List<T>` takes typed items, a key selector, and a
`renderItem` function; `BookApp` manages the collection with `useState` and adds
books from a form.

## Run the app

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To type-check and create a production build:

```sh
npm run build
```

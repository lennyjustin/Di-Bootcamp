# React + TypeScript Exercises XP

A Vite React application demonstrating the five exercises:

1. A React + TypeScript project scaffolded with Vite.
2. `Greeting.tsx`, a component with required, typed props.
3. `Counter.tsx`, using typed state to update a count and last action.
4. `UserCard.tsx`, with optional props and fallback values.
5. `UserList.tsx`, fetching typed user data with `useEffect` and reporting loading and error states.

## Run the app

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To check TypeScript and produce a
production build, run:

```sh
npm run build
```

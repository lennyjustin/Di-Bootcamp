The essentials, step by step

Follow the flow from a new account to a renewed session.

01

Know the three parts

The header names the algorithm, the payload carries claims, and the signature lets the server verify the token.

HEADER · PAYLOAD · SIGNATURE
02

Register & sign in

Validate credentials, hash passwords with bcrypt, then issue short-lived access and longer-lived refresh tokens.

HASH · SIGN · COOKIE
03

Protect your routes

Middleware verifies the access token before the server returns a private profile or accepts an update.

VERIFY · AUTHORIZE
04

Refresh & revoke

Rotate refresh tokens on use. Signing out revokes the active refresh session and clears both cookies.

ROTATE · REVOKE

# Week 7 Day 2 — Express and Knex APIs

This folder contains two standalone projects:

- `blog-api/` — Express + Knex + PostgreSQL blog CRUD API (port 3000).
- `book-api/` — Express book CRUD API with in-memory storage (port 5000).
- `user-auth-api/` — Express + Knex + PostgreSQL registration/login API using bcrypt.

See each project's README for setup and route details. The standalone projects use their own package manifests and directory structures.
